# Secretary style overrides — Westworld

Example chamber-provided overrides for the Secretary persona. The framework
globs `chambers/*/style/secretary.md` and, after applying the public persona
(`agents/secretary.md`), overlays every match — **one convention per heading**,
the heading being the key the merge compares. This file is illustrative: the
"owner" here is the park, and every name is fictional.
